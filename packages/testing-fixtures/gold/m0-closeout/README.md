# M0 closeout gold cases

These four synthetic cases close the intake-specific gaps without pretending that downstream
credit work is complete.

1. A company may start with one useful document. The file is accepted, the coverage it genuinely
   provides is credited and the next request remains a short governed batch.
2. An untidy room does not become complete because it contains many files. Only classified
   evidence discharges a requirement; unknown or duplicated volume stays visible without creating
   facts.
3. An advisor may prepare cases for several clients. Economic perimeter and authority remain
   case-scoped, and permission for a qualified introduction is never inherited from another case.
4. A stated capex request with signs of short-term liquidity pressure remains capex until reviewed.
   The system records the hypothesis and does not silently reroute the case.

The declarations live in `src/m0-closeout.ts`. Their executable behavior is tested against the
canonical replay in `@offroad/credit-playbook`; this fixture is not a second intake engine.
