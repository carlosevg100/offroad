# Gold case G1 — Rede Horizonte (synthetic)

Evaluation expectations for the intelligence layer (P1 plan §14.1). Everything here is
synthetic: the documents are the acceptance data room in `../../assets/rede-horizonte`,
and the expectations were derived from the synthetic answer key
`02_GABARITO_OFFROAD/01_GABARITO_Analise_Esperada_Offroad.xlsx` (which never enters the
product) plus the fixture candidates.

- `manifest.json` — case metadata, document list with SHA-256, provenance.
- `expected/fields.json` — generated by `pnpm --filter @offroad/evals gold:rede-horizonte`
  from `packages/evals/src/gold-rede-horizonte.ts`; a test fails if it drifts.
- `expected/profiles.json` — expected classification per document.
- `expected/exceptions.json` — RF-01..07 (red flags of the answer key) and MI-01..05
  (expected information requests), matched by rule id or keywords.
- `expected/calculations.json` — deterministic outputs the financial-core must reproduce.
- `expected/acceptance.json` — AC-01..09 with the automatic checks that evaluate them.

Baseline (fixture extractor): `pnpm --filter @offroad/evals baseline`.
